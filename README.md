# Weatherpane for macOS

Snow, rain, thunderstorms, hail and falling maple leaves on your desktop. Snow settles on windows and the Dock, you can roll snowballs and build snowmen, and the weather can follow the real conditions outside.

## Download

**[Download Weatherpane 1.4.1 (DMG)](https://github.com/Levkalink/weatherpane-releases/releases/latest)**

Requires macOS 13 or later. Runs on Apple Silicon and Intel.

1. Open the DMG and drag **Weatherpane** to **Applications**.
2. Launch it. The weather icon appears in the menu bar.
3. If macOS says it can't verify the developer, go to **System Settings → Privacy & Security** and click **Open Anyway**. You only need to do this once.

Updates install from inside the app: click the version number in the menu, or wait for the daily check.

---

This repository only hosts builds and the update feed (`appcast.xml`).
